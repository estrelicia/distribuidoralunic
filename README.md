# Distribuidora Lunic

Tienda WooCommerce en la copia local `https://distribuidoralunic.com.ar.dev/`. El tema público es `lunic`. Envíos, descuentos, checkout, búsqueda, filtro, categorías, el menú de categorías, contacto y cabeceras de seguridad viven en el plugin `distribuidora-lunic`.

Elementor Pro, JetEngine, Ivory Search y Product Filter están apagados. Elementor libre sigue activo para el pie, la tienda, la ficha y las páginas institucionales. El sitio en vivo no se modifica desde esta copia.

## Dónde está cada cosa

- Estado actual y reglas que siguen: `documentos/estado.md`
- Plan del plugin de CMS y seguridad (todavía sin código): `documentos/implementacion-plugin-cms.md`
- Política REST: `documentos/rest-api-lunic.md`
- Capturas de referencia: `documentos/linea-base/diseno/`
- Plan y actas ya cerradas: `documentos/archivo/`
- Plugin: `wp-content/plugins/distribuidora-lunic/`
- Tema: `wp-content/themes/lunic/`

## Entorno local

`wp-config.php` no se versiona: hay que crearlo en cada máquina con la base local. Las imágenes de `wp-content/uploads/` tampoco se suben.
