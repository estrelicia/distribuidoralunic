Nuevo método de envío para WooCommerce con opciones avanzadas y visualización modificada.

== Description ==

Este plugin crea un nuevo método de envío para WooCommerce con las siguientes características:

* Configuración de monto mínimo para envío gratuito
* Precio de envío para pedidos que no alcanzan el monto mínimo
* Opción de acarreo hasta la empresa de transporte
* Los envíos se muestran después del total en carrito, checkout y resumen de pedido
* Los costos de envío no se suman al total del pedido
* Compatibilidad completa con Elementor Pro

== Installation ==

1. Sube el plugin a la carpeta `/wp-content/plugins/`
2. Activa el plugin a través del menú 'Plugins' en WordPress
3. Configura el método de envío en WooCommerce > Ajustes > Envío
4. Añade el método de envío a una zona de envío

== Frequently Asked Questions ==

= ¿Los envíos se suman al total? =
No, los envíos nunca se suman al total según los requisitos del plugin.

= ¿Es compatible con Elementor Pro? =
Sí, el plugin es totalmente compatible con Elementor Pro y sus widgets de WooCommerce.
